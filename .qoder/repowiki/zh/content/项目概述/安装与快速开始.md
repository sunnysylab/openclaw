## 简介
本指南面向首次接触 OpenClaw 的用户，提供从零到一的完整安装与快速开始路径。你将了解系统要求、多种安装方式（npm/pnpm/bun）、从源码构建、初始配置（onboarding wizard）以及常见问题排查。我们还提供了针对个人用户、开发者与企业用户的快速上手建议。

## 系统要求与运行时
- 运行时：Node.js ≥ 22（推荐使用 pnpm 构建）
- 支持平台：macOS、Linux、Windows（强烈建议通过 WSL2 使用）
- 包管理器：npm、pnpm 或 bun（bun 仅用于本地开发体验）

## 安装方法总览
OpenClaw 提供多种安装方式，满足不同场景需求：
- 官方安装脚本（推荐）：自动检测/安装 Node，并一键运行 onboarding 向导
- npm/pnpm：手动安装后运行向导
- 从源码：适合贡献者或需要本地调试的用户
- 其他方式：Docker、Podman、Nix、Ansible、Bun（实验性）

## 平台安装指南
### macOS / Linux / WSL2（推荐）
- 使用官方安装脚本，自动处理 Node 检测、安装与 onboarding：
  - macOS/Linux：`curl -fsSL https://openclaw.ai/install.sh | bash`
  - Windows（PowerShell）：`iwr -useb https://openclaw.ai/install.ps1 | iex`
- 如需跳过 onboarding 或指定安装方式，可参考安装脚本的标志与环境变量说明。

### npm / pnpm
- npm：全局安装后运行 `openclaw onboard --install-daemon`
- pnpm：安装依赖后运行 `pnpm approve-builds -g`，再执行 onboarding

注意：若遇到 sharp 构建错误，可按文档指引设置环境变量以使用预编译二进制。

## 初始配置与向导
OpenClaw 推荐使用 onboarding wizard 完成首次配置，涵盖模型/认证、工作空间、网关、通道与守护进程等步骤。向导支持 QuickStart（默认）与 Advanced（完全控制）两种模式。

- 快速开始：运行 `openclaw onboard --install-daemon`
- 重新配置：使用 `openclaw configure` 或添加新代理 `openclaw agents add <name>`
- 非交互模式：使用 `--non-interactive`，或在 CI 中结合 JSON 输出

## 快速开始示例
以下示例基于官方文档与 README，帮助你在几分钟内完成安装、启动网关并发送第一条消息：

- 安装与 onboarding
  - 使用安装脚本：`curl -fsSL https://openclaw.ai/install.sh | bash`
  - 运行向导：`openclaw onboard --install-daemon`
- 启动网关（端口 18789，启用详细日志）
  - `openclaw gateway --port 18789 --verbose`
- 打开控制面板
  - `openclaw dashboard`
- 发送第一条消息（需已配置通道）
  - `openclaw message send --to +1234567890 --message "Hello from OpenClaw"`
- 与助手对话（可选）
  - `openclaw agent --message "Ship checklist" --thinking high`

## 故障排除指南
当遇到问题时，建议按“首分钟诊断”流程进行快速定位：

- 基础检查
  - `openclaw status`
  - `openclaw status --all`
  - `openclaw gateway probe`
  - `openclaw gateway status`
  - `openclaw doctor`
  - `openclaw channels status --probe`
  - `openclaw logs --follow`

- 常见问题与定位方向
  - 控制面板无法连接：检查网关绑定地址、认证模式与 Token；参考“Dashboard 或 Control UI 将不会连接”
  - 网关无法启动：检查服务状态、端口占用、非回环绑定缺少认证
  - 通道已连接但消息不流转：检查提及规则、配对/白名单策略
  - 浏览器工具失败：检查浏览器可执行文件路径、扩展附加状态
  - 节点工具失败：检查节点权限、前台状态、命令是否在允许列表中

- 重要提示
  - 若安装后命令不可用，优先检查 PATH 与全局前缀
  - 在 Linux 上遇到权限错误，可将 npm 全局前缀切换至用户目录

## 不同使用场景的快速上手
- 个人用户（初学者）
  - 使用安装脚本 + onboarding 向导，最快 5–15 分钟完成首次聊天
  - 无需通道即可通过控制面板进行测试
- 开发者（贡献者/本地调试）
  - 从源码克隆并构建，使用 `pnpm openclaw ...` 直接运行
  - 需要 pnpm 审批构建脚本（如 sharp、node-llama-cpp）
- 企业用户（生产部署）
  - 在 VPS/云主机上安装，使用 SSH/Tailscale 远程访问
  - 建议使用 Docker/Podman/Nix 等容器化方式部署
  - 通过向导配置安全策略（DM 配对、白名单、认证模式）

## 结语
通过本指南，你可以根据自身需求选择合适的安装方式，快速完成 OpenClaw 的首次配置与运行。遇到问题时，遵循“首分钟诊断”流程可大幅缩短排查时间。随着使用深入，建议逐步探索向导的高级选项、多代理与多通道配置，以及生产环境下的安全与可观测性实践。
